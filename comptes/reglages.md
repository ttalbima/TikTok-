# Réglages des trois comptes — liste à cocher

À faire une seule fois, environ 30 minutes au total. Les noms et l'emplacement des menus changent souvent selon les versions des applis : si un réglage n'est pas à l'endroit indiqué, cherche son nom dans la barre de recherche des paramètres.

## Mots à filtrer dans les commentaires (les trois réseaux)

Un compte sur l'argent attire les faux « conseillers » qui écrivent en commentaire pour piéger tes abonnés. Copie cette liste dans le filtre de mots de chaque réseau :

```
whatsapp, telegram, wa.me, t.me, investir, investissement, investis, crypto, bitcoin, trading, trader, forex, gagner de l'argent, revenus passifs, contacte-moi, écris-moi, envoie-moi un message, mon numéro, dm moi, coach financier, gestionnaire de compte, retrait garanti
```

## YouTube (sur ordinateur, dans YouTube Studio : studio.youtube.com)

Vérifie d'abord, en haut à droite, que tu es bien sur la chaîne « Les pièges de l'argent » et pas sur ta chaîne personnelle.

**Personnalisation**
- [ ] Profil : nom, identifiant `@piegesdelargent`, photo, bannière, description (texte dans `guide-comptes.md`).
- [ ] Profil, « Coordonnées » : l'adresse e-mail du projet (facultatif, pour les contacts professionnels plus tard).
- [ ] Liens : aucun pour l'instant.

**Paramètres** (roue dentée en bas à gauche)
- [ ] Chaîne > Informations de base : pays de résidence **France** ; mots-clés : `pièges argent, arnaques, consommation, prix, abonnements, astuces conso, économie du quotidien`.
- [ ] Chaîne > Paramètres avancés : audience **« Non, ma chaîne n'est pas conçue pour les enfants »**. Important : si tu te trompes, les commentaires et une partie des recommandations sont coupés.
- [ ] Valeurs par défaut des mises en ligne :
  - catégorie **Éducation** ;
  - langue de la vidéo **Français** ;
  - licence standard ;
  - commentaires : **« Conserver les commentaires potentiellement inappropriés pour examen »** ;
  - visibilité : publique (ou programmée).
- [ ] Communauté > Paramètres automatiques : colle la liste des mots à filtrer dans « Mots bloqués », et coche **« Bloquer les liens »**.

**Vérification du compte**
- [ ] Paramètres > Chaîne > Éligibilité aux fonctionnalités : valide ton numéro de téléphone (débloque les fonctions intermédiaires, comme les vidéos longues et les miniatures personnalisées).

**Contenu généré par IA, à chaque mise en ligne**
- La case « Contenu modifié ou synthétique » concerne les contenus **réalistes**. Nos vidéos sont des animations clairement non réalistes et la voix de synthèse n'imite pas une personne réelle : d'après l'aide officielle de YouTube, la déclaration n'est alors pas obligatoire. C'est mon interprétation ; si tu préfères la prudence, cocher « Oui » ne réduit ni l'audience ni la rémunération, selon YouTube.

## TikTok (dans l'appli, Profil > menu ☰ > Paramètres et confidentialité)

**Compte**
- [ ] Garde un **compte personnel** (pas Entreprise) : d'après les guides consultés, les comptes Entreprise sont exclus du programme de rémunération.
- [ ] Langue de l'appli : français.

**Confidentialité**
- [ ] Compte privé : **désactivé** (compte public).
- [ ] « Suggérer ton compte aux autres » : **désactive** contacts et amis Facebook, pour ne pas mélanger avec ta vie personnelle.
- [ ] Commentaires : tout le monde. Puis « Filtres de commentaires » : active le filtre des commentaires indésirables et offensants, active « Filtrer les mots-clés » et colle la liste.
- [ ] Mentions, Duo, Collage : tout le monde (ça aide la diffusion).
- [ ] Téléchargements : autorisés (les gens partagent plus facilement).
- [ ] Messages directs : **amis mutuels uniquement** (limite les arnaqueurs).

**Sécurité**
- [ ] Validation en deux étapes activée.

**À chaque publication** (écran « Publier », section « Plus d'options »)
- [ ] Étiquette **« Contenu généré par IA »** cochée.
- [ ] « Autoriser l'importation en haute qualité » activé si l'option apparaît (elle n'existe pas sur toutes les versions).
- [ ] Commentaires, Duo et Collage autorisés.

**Programmer à l'avance**
- Sur ordinateur, dans TikTok Studio : d'après plusieurs guides, jusqu'à 10 jours à l'avance. Un guide affirme que les comptes personnels ne peuvent pas programmer : si l'option n'apparaît pas chez toi, **ne passe pas en compte Entreprise** pour l'obtenir, publie directement depuis l'appli.

## Instagram (dans l'appli, Profil > menu ☰)

**Compte**
- [ ] Type de compte et outils : compte professionnel > **Créateur**, catégorie **Éducation**.
- [ ] Afficher la catégorie sur le profil : au choix (je la laisserais masquée).
- [ ] Centre de comptes : vérifie que ce compte n'est pas relié à ton compte Facebook ou Instagram personnel, sauf si tu le veux.

**Qualité**
- [ ] Utilisation des données et qualité des médias : **« Importer à la qualité la plus élevée »** activé. Il est désactivé par défaut, d'après plusieurs guides.

**Interactions**
- [ ] Mots masqués : active « Masquer les commentaires » et « Masquer les commentaires plus offensants » ; dans « Gérer les mots et expressions personnalisés », colle la liste.
- [ ] Messages : laisse les demandes de messages filtrées (par défaut).
- [ ] Remix : autorisé.

**Sécurité**
- [ ] Centre de comptes > Mot de passe et sécurité : authentification à deux facteurs.

**À chaque publication**
- [ ] Partage vers Facebook : à activer si l'option est proposée (visibilité en plus, zéro travail).
- [ ] Programmation : « Paramètres avancés » > « Programmer ce reel ».
